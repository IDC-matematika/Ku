# Boğ va mevalar — interaktiv daftar

IDC Kids (3–4 yosh) ish daftarining 1-bobi (8–28-betlar) asosida tayyorlangan interaktiv sahifa.
Har bir bet alohida o'yin: yashirin narsalarni topish, soyani ulash, punktir bo'ylab chizish, naqsh,
savatlarga ajratish, sanash, labirint, farqni topish, nuqtali chizma, bo'yash va boshqalar.

- `index.html` — sahifa (Artifact formatida: `<!doctype>`/`<head>` qatlami nashr paytida qo'shiladi).
- `img/` — PDF ichidan ajratib olingan rasmlar (webp/png).

Bajarilgan topshiriqlar va «yoqdi / qiyin edi» belgilari faqat brauzerning localStorage'ida saqlanadi.
